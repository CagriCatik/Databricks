# Databricks LLM fine‑tuning

* Databricks documentation: *Large language models (LLMs) on Databricks* — overview of fine‑tuning features including Foundation Model Fine‑tuning with MLflow + Unity Catalog integration ([notebooks.databricks.com][1], [Databricks Dokumentation][2])
* Tutorial: *Create and deploy a Foundation Model Fine‑tuning run* — guides through API/UI steps using `databricks_genai`, training run setup, evaluation and model serving ([Databricks Dokumentation][3])
* Technical blog: *Getting started with fine‑tuning on Databricks* — covers data preparation, tuning steps, deployment tips and best practices with Mosaic AI Model Training ([community.databricks.com][4])
* Demo: *Fine‑Tune Your LLM on Databricks for Specialized Tasks and Knowledge* — interactive demo showcasing Llama fine‑tuning, deployment and querying ([Databricks][5])
* Demo notebook: *Fine Tune your LLMs with Mosaic AI Model Training* — hands‑on notebook example using Mosaic AI FT API ([notebooks.databricks.com][1])
* Technical blog: *End‑to‑End Structured Extraction with LLM – Part 2: Fine‑Tuning with Synthetic Data* — fine‑tuning for structured extraction tasks, synthetic sample generation, improving F1 score ([community.databricks.com][6])
* Technical blog: *Distributed Fine‑Tuning of LLMs on Databricks Lakehouse with Ray and DeepSpeed* — how to scale tuning of larger models (e.g. Falcon‑7B, Llama‑2 13B) using Ray AIR and DeepSpeed ([community.databricks.com][7])
* GitHub repo: *mastering‑fine‑tuning‑databricks* — sample notebook repository with five LLM fine‑tuning use cases (customer support chatbot, summarization, sentiment, translation, etc.) ([github.com][8])
