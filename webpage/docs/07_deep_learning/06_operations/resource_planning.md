# Resource Planning

Resource planning aligns computational needs with available budget and infrastructure.

## Capacity planning

- Estimate data volume, model size, and expected training time.
- Choose GPU types and cluster sizes based on benchmarks or prior projects.
- Plan for peak periods such as intense tuning or large backfills.

## Cost controls

- Use cluster policies with strict limits.
- Prefer spot or preemptible instances where supported and appropriate.
- Use autotermination and schedule windows for non-critical workloads.

Regularly review usage and refine assumptions as the project evolves.
